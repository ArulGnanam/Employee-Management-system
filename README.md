# Employee Management System

A basic web-based Employee Management System built using **Java Servlets, JSP, JDBC, MySQL, HTML, CSS, and JavaScript**.

### Features

* Admin Login
* Employee CRUD Operations
* Department Management
* Attendance Management
* Salary Management
* MySQL Database Integration

### Technologies

**Java | Servlets | JSP | JDBC | MySQL | HTML | CSS | JavaScript | Maven | Tomcat**
